# Release 1.3.52

## Summary
**1.3.52** ships the Android legacy SKU billing catalog fallback (#1684, #1736): when Play Billing reports `PRODUCT_DETAILS` unsupported, the paywall loads known SKUs (`pro_base`, `elite_tactical`, `elite_tactical_monthly`) instead of an empty catalog.

## Product
- **Android billing:** Legacy SKU catalog fallback for devices/clients without `PRODUCT_DETAILS`; restores paywall product availability for affected users.
- **Ops:** Closes #1684 (`billing_product_catalog_status` empty on legacy Billing clients).

## Release operations
- Ship: `release/v1.3.52` → `native-release` `platform=android` `android_track=production` after `internal-signoff/firebase` on this release SHA.
- Supersedes Play build **1778679351** (v1.3.51).
