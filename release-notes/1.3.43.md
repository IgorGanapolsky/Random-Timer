# Release 1.3.43

## Summary
**1.3.43** ships monetization ROI (annual-default paywall on high-intent gates) and Android AdMob rewarded-ad infrastructure for a one-session Pro sound trial. PostHog flag `rewarded_ads_enabled` remains **off** until app-ads.txt and AdMob verification complete.

## Product
- **Paywall:** Annual plan pre-selected on voice, range, sound arsenal, repeat, and qualified-training gates; auto `paywall_offer_select` on open.
- **Android rewarded ads:** AdMob SDK + Sound Arsenal “watch ad to try one Pro sound” when flag enabled.
- **Analytics:** Paywall report counts catalog failures without double-counting status events.

## Release operations
- Host `app-ads.txt` at `https://igorganapolsky.github.io/Random-Timer/app-ads.txt` (verified in CI).
- Enable `rewarded_ads_enabled` in PostHog only after AdMob app verification and payment profile complete.
