# Release 1.3.49

## Summary
**1.3.49** hardens Android Play Billing catalog load: batched `queryProductDetails` by product type, deduped monthly→`elite_tactical` probe, stronger retries, prepaid pending purchases for subscriptions.

## Product
- **Android:** Paywall catalog queries batch INAPP + SUBS separately; `elite_tactical_monthly` maps to `elite_tactical` without duplicate Play probes.
- **Android:** Up to 5 catalog query attempts with capped exponential backoff; reconnect on `SERVICE_DISCONNECTED`.
- **Android:** `enablePendingPurchases` with prepaid support for subscription SKUs.

## Release operations
- Requires active Play products: `elite_tactical` (annual + P1M), `pro_base` (one-time).
- Ship: `release/v1.3.49` → `native-release` `platform=android` `android_track=production` after `internal-signoff/firebase` on release SHA.
- Post-deploy: verify PostHog `billing_product_catalog_status` → `ok` on new `$app_build` (telemetry only — not ledger revenue).
