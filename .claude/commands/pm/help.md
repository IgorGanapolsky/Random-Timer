Available PM commands:
- `/pm:status` — Project overview
- `/pm:next` — Available tasks
- `/pm:blocked` — Blocked tasks
- `/pm:in-progress` — Active work
- `/pm:standup` — Daily standup
- `/pm:prd-new` — Create PRD
- `/pm:prd-parse` — PRD to epic
- `/pm:prd-list` — List PRDs
- `/pm:epic-list` — List epics
- `/pm:epic-show <name>` — Epic details
- `/pm:epic-decompose <name>` — Break into tasks
- `/pm:epic-close <name>` — Complete epic
- `/pm:search <term>` — Search artifacts
- `/pm:validate` — Check integrity

All commands read `.claude/prds/` and `.claude/epics/` directly.
