# Stack Overflow answer drafts

Each file is paste-ready Markdown for Stack Overflow.

- **Filename:** `{question-id}-{short-slug}.md`
- **Content:** Answer text only—no YAML, no wrapper headings.
- **Repo links:** Every draft must include at least one **`develop`** permalink to real usage in this repo (`https://github.com/IgorGanapolsky/Random-Timer/blob/develop/...`). If we don’t ship that pattern, say so briefly and stick to generic guidance only for that part—don’t invent links.

Nothing auto-posts.
