# UI/UX Audit Baseline (2026-02-21)

## Truth

- A full cross-platform UI/UX audit was not completed before the `1.1.1` release.
- The process had targeted fixes, but no enforced release gate for complete usability/accessibility review.

## Standards Used (Current Official Sources)

- Apple App Store Connect: Product Page Accessibility
  - https://developer.apple.com/help/app-store-connect/manage-app-accessibility/product-page-accessibility
- Android adaptive UI guidance (latest platform guidance pages)
  - https://developer.android.com/design/ui/mobile/guides/foundations/adaptive-design/support-different-screen-sizes
- Android inclusive design guidance
  - https://developer.android.com/design/ui/mobile/guides/foundations/inclusive-design

## Immediate Findings

- Paused timer state looked visually dim, reducing readability of status/context text.
- Resume button visual language was inconsistent with the rest of the app's primary action styling.

## Fixes Applied

- iOS:
  - Stop text breathing animation when timer enters `paused`.
  - Increase paused ring track visibility.
  - Use stronger text contrast for paused labels/info.
  - Keep primary action visual style consistent in paused state.
- Android:
  - Increase paused-state text contrast in status and info text.
  - Increase paused-state range label contrast.

## Verification Run

- Android unit tests:
  - `cd native-android && ./gradlew testDebugUnitTest` -> PASS
- iOS tests on simulator:
  - `cd native-ios && xcodebuild -scheme RandomTimer -destination 'platform=iOS Simulator,name=iPhone 17,OS=26.1' test -quiet` -> PASS
- Android lint:
  - `cd native-android && ./gradlew lint` -> FAILED due toolchain lint crash (`IncompatibleClassChangeError` in Compose/Lifecycle lint detectors), not app logic failure.

## Policy Going Forward

- No release without:
  - iOS + Android test pass
  - screenshot/readability check for running, paused, alarm states
  - accessibility/contrast check against official platform guidance
  - explicit audit artifact in `docs/` for the release
