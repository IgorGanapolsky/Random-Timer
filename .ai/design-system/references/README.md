# 参考截图 — 设计师放图指南

> AI（Claude / Cursor）是多模态的，能直接**看图理解布局和风格**。
> 将设计稿截图放在此目录，AI 生成页面时会参考这些图片。

## 怎么放

1. 在 Figma / Sketch 中导出关键页面截图
2. 命名为对应页面类型（见下表）
3. 放到本目录

## 文件命名

| 文件名 | 内容 | 必要性 |
|--------|------|--------|
| `dashboard.png` | 数据看板/首页 | 推荐 |
| `list-page.png` | CRUD 列表页 | 推荐 |
| `form-page.png` | 新增/编辑表单页 | 推荐 |
| `detail-page.png` | 详情页 | 推荐 |
| `login.png` | 登录页 | 可选 |
| `color-palette.png` | 色彩规范图 | 可选 |
| `typography.png` | 字体层级规范图 | 可选 |

## 截图要求

| 要求 | 说明 |
|------|------|
| 分辨率 | 1x 即可（1440px 宽度），不需要 2x |
| 格式 | PNG（界面截图）或 JPG（含照片时） |
| 内容 | **包含真实/模拟数据**，不要空白页面 |
| 数量 | 4-6 张关键页面即可 |
| 标注 | 不需要标注像素值——精确数值在 `tokens.json` 中 |

## AI 看图能力

**能理解：**
- 整体布局结构（侧边栏位置、内容区分布）
- 色调和视觉风格（冷暖色调、简约/丰富）
- 元素排列方式（卡片排列、表格样式）
- 信息层级（标题大小、内容密度）

**不能精确提取：**
- 精确像素值 → 用 `tokens.json`
- 精确颜色代码 → 用 `tokens.json`
- 字体名称 → 用 `tokens.json`

**所以：图片给风格感知，tokens.json 给精确数值，二者缺一不可。**

## 没有设计稿怎么办

不放截图也完全可以——AI 会依据 `tokens.json` + `brand.md` + `pages.md` 的文字描述生成页面。截图是**加分项**，不是必须项。
