# 标准页面模板

> AI 生成页面时必须遵循以下模板。每种页面类型有固定的布局结构和组件选择。
> 如有参考截图，见 `references/` 目录。

## 模板 1: CRUD 列表页（最常用）

**布局结构：**

```
┌─────────────────────────────────────────────────────┐
│  PageHeader: 页面标题                   [新增] 按钮   │
├─────────────────────────────────────────────────────┤
│  SearchBar (ProTable 自动生成)                       │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌────────────────┐     │
│  │ 字段1 │ │ 字段2 │ │ 字段3 │ │ [查询] [重置]  │     │
│  └──────┘ └──────┘ └──────┘ └────────────────┘     │
├─────────────────────────────────────────────────────┤
│  DataTable                                          │
│  ┌────┬──────┬──────┬──────┬──────┬────────┐        │
│  │ ID │ 名称  │ 状态  │ 时间  │ ...  │ 操作   │        │
│  ├────┼──────┼──────┼──────┼──────┼────────┤        │
│  │ 1  │ xxx  │ [Tag]│ date │ ...  │ 编辑 删除│        │
│  │ 2  │ xxx  │ [Tag]│ date │ ...  │ 编辑 删除│        │
│  └────┴──────┴──────┴──────┴──────┴────────┘        │
│                                                     │
│  共 100 条  < 1 2 3 ... 10 >    20条/页 ▼           │
└─────────────────────────────────────────────────────┘
```

**规则：**
- 搜索栏字段不超过 4 个，超出的折叠到"展开"按钮
- 新增按钮在右上角，`primary` 样式，带 `+` 图标
- 操作列不超过 3 个文字链接，超出用"更多"下拉菜单
- 删除操作必须有 `Popconfirm` 二次确认
- 分页显示总条数 + 每页条数选择器

**参考截图（如有）：** `references/list-page.png`

## 模板 2: 数据看板页

**布局结构：**

```
┌─────────────────────────────────────────────────────┐
│  PageHeader: 数据看板                   日期选择器    │
├─────────────────────────────────────────────────────┤
│  StatCards (4列等宽)                                 │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐│
│  │ 总用户数   │ │ 今日新增   │ │ 活跃用户   │ │ 转化率    ││
│  │ 12,345   │ │ 234 ↑12% │ │ 8,901    │ │ 67.8%   ││
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘│
├─────────────────────────────────────────────────────┤
│  Charts (2列)                                       │
│  ┌────────────────────┐ ┌────────────────────┐      │
│  │                    │ │                    │      │
│  │   折线图/柱状图      │ │   饼图/排行榜        │      │
│  │   (趋势数据)        │ │   (分布数据)         │      │
│  │                    │ │                    │      │
│  └────────────────────┘ └────────────────────┘      │
├─────────────────────────────────────────────────────┤
│  DetailTable (可选)                                  │
│  ┌─────────────────────────────────────────────┐    │
│  │  明细数据表格                                 │    │
│  └─────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────┘
```

**规则：**
- 统计卡片 4 个一排，包含：数值 + 环比/同比趋势（箭头 + 百分比）
- 数值用 `stat-value` 字号（30px Semibold）
- 趋势上升用绿色箭头，下降用红色箭头
- 图表区固定高度 300-400px
- 左图用折线/柱状（展示趋势），右图用饼图/排行（展示分布）
- 图表颜色使用 Ant Design 色板，不自定义

**参考截图（如有）：** `references/dashboard.png`

## 模板 3: 表单页

**布局结构：**

```
┌─────────────────────────────────────────────────────┐
│  PageHeader: 新增/编辑 XXX          [返回] 按钮      │
├─────────────────────────────────────────────────────┤
│  Card                                               │
│  ┌─────────────────────────────────────────────┐    │
│  │  分组标题: 基本信息                            │    │
│  │  ┌──────────────┐  ┌──────────────┐         │    │
│  │  │ 字段1         │  │ 字段2         │         │    │
│  │  └──────────────┘  └──────────────┘         │    │
│  │  ┌──────────────┐  ┌──────────────┐         │    │
│  │  │ 字段3         │  │ 字段4         │         │    │
│  │  └──────────────┘  └──────────────┘         │    │
│  │                                              │    │
│  │  ─ ─ ─ ─ ─ Divider ─ ─ ─ ─ ─               │    │
│  │                                              │    │
│  │  分组标题: 详细配置                            │    │
│  │  ┌──────────────┐  ┌──────────────┐         │    │
│  │  │ 字段5         │  │ 字段6         │         │    │
│  │  └──────────────┘  └──────────────┘         │    │
│  │                                              │    │
│  │  [提交]  [取消]                               │    │
│  └─────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────┘
```

**规则：**
- 表单外包一层 `Card`
- 字段超过 4 个时使用 2 列布局（`ProForm.Group`）
- 超过 8 个字段时用 `Divider` 分组或改用 `StepsForm`
- 字段宽度：短字段 `width="sm"` (216px)，长字段 `width="md"` (328px)
- 提交按钮靠左，取消按钮在右侧

**参考截图（如有）：** `references/form-page.png`

## 模板 4: 详情页

**布局结构：**

```
┌─────────────────────────────────────────────────────┐
│  PageHeader: XXX 详情              [编辑] [删除]     │
├─────────────────────────────────────────────────────┤
│  Card: 基本信息                                      │
│  ┌─────────────────────────────────────────────┐    │
│  │  ProDescriptions (2-3 列)                    │    │
│  │  ID: xxx        状态: [Tag]                  │    │
│  │  名称: xxx      创建时间: xxxx-xx-xx          │    │
│  │  邮箱: xxx      更新时间: xxxx-xx-xx          │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  Card: 关联数据                                      │
│  ┌─────────────────────────────────────────────┐    │
│  │  ProTable (关联列表)                          │    │
│  └─────────────────────────────────────────────┘    │
│                                                     │
│  Card: 操作日志 (可选)                                │
│  ┌─────────────────────────────────────────────┐    │
│  │  Timeline                                    │    │
│  │  ● 2026-03-11 管理员 修改了状态               │    │
│  │  ● 2026-03-10 系统 自动创建                   │    │
│  └─────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────┘
```

**规则：**
- 基本信息用 `ProDescriptions` 组件，2-3 列布局
- 状态字段用 `Tag` / `Badge` 渲染
- 操作按钮（编辑/删除）在 PageHeader 右侧
- 关联数据用 `ProTable`
- 操作日志用 `Timeline`（倒序，最新在上）
- 各区块用独立 `Card` 分隔，间距 `spacing.section-gap` (24px)

**参考截图（如有）：** `references/detail-page.png`

## 模板 5: 登录页

**布局结构：**

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│                                                     │
│              ┌─────────────────┐                    │
│              │     Logo        │                    │
│              │   系统名称       │                    │
│              │                 │                    │
│              │  ┌───────────┐  │                    │
│              │  │ 用户名     │  │                    │
│              │  └───────────┘  │                    │
│              │  ┌───────────┐  │                    │
│              │  │ 密码       │  │                    │
│              │  └───────────┘  │                    │
│              │                 │                    │
│              │  [   登录   ]   │                    │
│              │                 │                    │
│              └─────────────────┘                    │
│                                                     │
│              © 2026 公司名称                         │
└─────────────────────────────────────────────────────┘
```

**规则：**
- 表单区域居中，宽度 400px
- 背景纯色 `#f5f5f5` 或浅渐变（唯一允许渐变的页面）
- Logo + 系统名称在表单上方
- 登录按钮 `primary`，100% 宽度
- 底部版权信息，12px 灰色

**参考截图（如有）：** `references/login.png`

## 通用布局规则

| 规则 | 说明 |
|------|------|
| 页面底色 | `#f5f5f5`（token: `background.page`） |
| 内容容器 | 白色 Card，统一间距 |
| 页面内边距 | 24px（token: `spacing.page-padding`） |
| 区块间距 | 24px（token: `spacing.section-gap`） |
| 内容最大宽 | 1600px 居中（token: `layout.content-max-width`） |
| 面包屑 | ProLayout 自动生成，不手动写 |
