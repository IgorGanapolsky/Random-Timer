# 组件设计规范

> AI 在使用 UI 组件时必须遵循以下规范，确保全项目视觉统一。

## 按钮 Button

| 类型 | 使用场景 | 数量限制 |
|------|---------|---------|
| `primary` | 页面主操作（新增、提交、确认） | 每个视图区域最多 1 个 |
| `default` | 次要操作（取消、重置、导出） | 不限 |
| `link` | 表格行内操作、文字链接 | 不限 |
| `text` | 工具栏图标按钮 | 不限 |
| `dashed` | 添加条目（虚线框"+"） | 特定场景 |

**规则：**
- 按钮文字 2-4 个字（"新增"、"提交"、"导出报表"）
- 操作栏按钮从左到右重要性递减
- 危险操作用 `danger` 属性，不改变按钮类型
- 加载中必须显示 `loading` 状态 + 禁用点击

## 表格 Table

**列宽：**
| 内容类型 | 建议宽度 |
|---------|---------|
| ID / 序号 | 80px |
| 姓名 / 短文本 | 120-160px |
| 邮箱 / 长文本 | 200-260px |
| 状态标签 | 100px |
| 时间 | 180px |
| 操作列 | 150-200px |

**规则：**
- 表头文字左对齐，数字列右对齐
- 超长文本用 `ellipsis` 截断 + Tooltip 展示全文
- 状态列用 `Badge` 或 `Tag` 展示，不用纯文字
- 空数据显示 `Empty` 组件，不要空白
- 斑马纹可选（`#fafafa` 间隔），密集数据建议开启

## 表单 Form

**布局：**
| 场景 | 布局 | 列数 |
|------|------|------|
| 标准表单页 | `vertical` | 1-2 列 |
| 搜索栏 | `inline` | 3-4 列 |
| 弹窗表单 | `vertical` | 1 列 |
| 设置页 | `horizontal` | 1 列，label 宽 120px |

**规则：**
- 必填字段标 `*` (antd 自动处理)
- 每个输入框有 `placeholder` 提示
- 关联字段在视觉上分组（用 `ProForm.Group` 或 `Divider`）
- 提交按钮在表单底部靠左
- 取消按钮在提交按钮右侧，`default` 样式

## 卡片 Card

**使用场景：**
| 场景 | Card 类型 |
|------|----------|
| 数据分区 | 带标题的 Card |
| 统计数字 | 无标题 Card + 大数字 |
| 独立功能区 | 带标题 + 右上角操作 |

**规则：**
- 卡片内边距 24px（token: `spacing.card-padding`）
- 卡片间距 16px（token: `spacing.card-gap`）
- 卡片标题 16px Semibold（token: `typography.card-title`）
- 不要嵌套卡片（Card 内不放 Card）
- 卡片底色白色，页面底色灰色，靠对比区分

## 弹窗 Modal

| 内容类型 | 宽度 |
|---------|------|
| 简单确认 | 416px (默认) |
| 表单弹窗 | 520px |
| 复杂内容/预览 | 720px |
| 大数据展示 | 1000px |

**规则：**
- 标题简明（"确认删除" 而非 "你确定要删除这条记录吗？"）
- 确认按钮在右下角
- 危险操作的确认弹窗：标题含操作名，内容含影响说明
- 弹窗高度不超过视窗 80%，超出内容区滚动

## 标签 Tag / Badge

**状态标签色彩映射：**
| 状态语义 | 颜色 | 示例 |
|---------|------|------|
| 进行中/活跃 | `processing` (蓝色) | 进行中、启用、在线 |
| 成功/完成 | `success` (绿色) | 已完成、已通过、正常 |
| 警告/待处理 | `warning` (橙色) | 待审核、即将过期 |
| 错误/失败 | `error` (红色) | 失败、已拒绝、异常 |
| 默认/未开始 | `default` (灰色) | 草稿、未开始、已关闭 |

**规则：**
- 同一个状态在全项目中颜色必须一致
- Tag 文字 2-4 个字
- 不超过 5 种状态颜色

## 空状态 Empty

- 列表无数据：使用 Ant Design `Empty` 组件
- 搜索无结果：显示"未找到相关结果"+ 清除筛选按钮
- 页面无权限：显示 403 页面 + 返回按钮
- 不要显示空白页面——任何"无内容"都要有明确提示

## 加载状态 Loading

| 场景 | 方式 |
|------|------|
| 页面加载 | `Spin` 居中 |
| 表格加载 | ProTable 内置 `loading` |
| 按钮提交 | Button `loading` 属性 |
| 局部内容 | `Skeleton` 骨架屏 |

**规则：**
- 任何异步操作必须有加载反馈
- 加载超过 300ms 才显示（避免闪烁）
- 骨架屏用于首次加载，Spin 用于刷新/切换
