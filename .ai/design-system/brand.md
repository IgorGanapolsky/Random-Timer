# 品牌视觉规范

> 本文件定义项目的整体视觉风格。AI 在生成任何前端页面时必须遵循这些原则。
> 精确数值引用 `tokens.json`，本文件聚焦"为什么"和"怎么用"。

## 风格定位

- **专业、简洁、高效**的企业级中台风格
- 信息密度适中，**留白充足**
- 弱装饰、强功能，**内容优先**
- 视觉层级清晰：标题 → 正文 → 辅助信息 → 操作区

## 色彩使用原则

### 主色（品牌蓝 #1677ff）

| 场景 | 使用 |
|------|------|
| 主操作按钮 | `type="primary"` |
| 选中/激活态 | 菜单选中、Tab 选中、表格选中行 |
| 链接文字 | 可点击的文字链接 |
| 进度/加载指示器 | 进度条、加载动画 |

**禁止**：大面积使用主色作为背景。主色仅用于**焦点元素**。

### 功能色

| 色彩 | 含义 | 使用场景 |
|------|------|---------|
| 绿色 `#52c41a` | 成功/通过/增长 | 成功提示、审核通过、数据上升 |
| 橙色 `#faad14` | 警告/待处理 | 警告提示、待审核、异常但非错误 |
| 红色 `#ff4d4f` | 错误/失败/下降 | 错误提示、删除确认、数据下降 |

**规则**：功能色只用于**状态反馈**，不用于装饰。

### 中性色

- **文字**靠透明度区分层级（88% / 65% / 25%），不用不同颜色
- **背景**只用灰白：页面底 `#f5f5f5` + 容器白 `#ffffff`
- **边框/分割线**统一 `#d9d9d9`

### 配色禁区

- 禁止使用渐变色背景
- 禁止使用 tokens.json 以外的颜色值
- 禁止在同一页面使用超过 3 种强调色
- 禁止在数据表格中使用彩色行背景（用 Badge/Tag 标识状态）

## 间距原则

**4px 倍数系统**——所有间距必须是 4 的整数倍。

| 场景 | 间距 | Token |
|------|------|-------|
| 紧凑元素内部 | 4px | `spacing.xs` |
| 标签与内容 | 8px | `spacing.sm` |
| 同级元素之间 | 16px | `spacing.md` |
| 不同区块之间 | 24px | `spacing.lg` |
| 页面内容内边距 | 24px | `spacing.page-padding` |
| 卡片内边距 | 24px | `spacing.card-padding` |

**禁止**：使用非 4 倍数的间距值（如 5px, 10px, 15px, 13px）。

## 字体层级

| 层级 | 字号 | 字重 | 使用场景 |
|------|------|------|---------|
| 页面标题 | 20px | Semibold | 页面顶部标题 |
| 卡片标题 | 16px | Semibold | Card / Section 标题 |
| 正文 | 14px | Regular | 表格内容、表单标签、描述文字 |
| 正文加粗 | 14px | Semibold | 表格列标题、表单分组标题 |
| 辅助说明 | 12px | Regular | 帮助文字、时间戳、标签 |
| 统计数字 | 30px | Semibold | 看板页大数字 |

**规则**：
- 字号只用上面 5 档，不要自创尺寸
- 层级靠字号 + 字重 + 颜色透明度区分
- 不用下划线强调（链接除外）
- 不用斜体

## 圆角

| 元素 | 圆角 | 说明 |
|------|------|------|
| Tag / Badge | 4px | 小元素 |
| Button / Input / Card | 6px | 中型元素（默认） |
| Modal / Drawer | 8px | 大型浮层 |
| Avatar / 胶囊按钮 | 9999px | 完全圆形 |

**禁止**：圆角大于 8px（圆形除外）。

## 阴影

| 级别 | 使用场景 |
|------|---------|
| 无阴影 | 页面内嵌卡片（靠边框区分） |
| `shadow.sm` | 卡片默认状态 |
| `shadow.md` | 悬浮态、下拉菜单 |
| `shadow.lg` | Modal、Drawer 浮层 |

**规则**：阴影用于表示元素的**层叠关系**，层级越高阴影越重。

## 图标风格

- 使用 **Outlined（线性）** 图标风格，不用 Filled（填充）
- 来源：`@ant-design/icons` Outlined 系列
- 行内图标尺寸 16px，导航图标 20-24px
- 图标颜色跟随所在位置文字颜色
- 不要对图标加额外背景色/圆形底色（除通知角标）

## 动效

- 过渡时长 0.3s（标准）/ 0.15s（快速，hover 态）
- 缓动函数 `ease`（Ant Design 默认）
- 仅在状态切换时使用动效（展开/收起、显示/隐藏）
- 不要添加装饰性动画（入场动画、弹跳效果）
