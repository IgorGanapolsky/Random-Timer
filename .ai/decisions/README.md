# Architecture Decision Records (ADR)

This directory contains Architecture Decision Records for the Random-Timer project.

## What is an ADR?

An ADR records an important architectural or technical decision, including the context, the decision itself, and its consequences. ADRs help AI agents and team members understand **why** decisions were made, not just what was done.

## File Naming

```
NNN-short-description.md
```

- `NNN`: Three-digit sequential number (001, 002, ...)
- `short-description`: Kebab-case summary of the decision

## Template

Use `.ai/decisions/_template.md` as the starting point for new ADRs.

## Status Values

| Status | Meaning |
|--------|---------|
| proposed | Under discussion, not yet decided |
| accepted | Decision made and in effect |
| deprecated | Was accepted but no longer applies |
| superseded | Replaced by a newer ADR (link to replacement) |
