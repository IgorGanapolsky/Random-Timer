# Changelog

Monthly changelog files for **Random-Timer**.

## Format

Each month gets its own file: `YYYY-MM.md`

Entries follow this format:

```markdown
## [YYYY-MM-DD] <type>: <short description>

- **What**: What was changed
- **Why**: The motivation
- **Impact**: What else is affected
- **Gotchas**: Non-obvious side effects (if any)
- **Related**: Links to ADRs, commits, issues
```

Type values: `feat`, `fix`, `refactor`, `perf`, `config`, `deps`
